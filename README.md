# 📦 Android Package Viewer

一个简单的工具，可以复制应用的包名。支持搜索过滤和应用分类，可以自定义分类名称，以及区分用户应用和系统应用。简洁无广告。

A simple, clean, and ad-free tool to view and copy Android package names. Supports search filtering, custom app categorization, and distinguishes between user and system apps.

## ✨ 核心功能 (Features)
- 🔍 支持搜索过滤 (Search filtering)
- 📋 一键复制包名 (Copy package name easily)
- 📂 自定义应用分类名称 (Custom app categorization)
- 📱 区分用户/系统应用 (User/System app distinction)
- 🚫 简洁无广告 (Clean and Ad-free)
